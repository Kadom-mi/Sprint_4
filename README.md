Sprint_4
### Автоматизированные тесты для [учебного сервиса Яндекс Самокат](https://qa-scooter.praktikum-services.ru/).

## 1. Подготовка проекта

### 1. Собрать Maven‑проект в IDE
### 2. Использовать Java 11
### 3. Подключить зависимости
  В проекте должны быть подключены следующие зависимости:
  * **JUnit 4** — для написания и запуска тестов.
  * **Selenium** — для автоматизации взаимодействия с браузером.
### 4. Установить браузеры
  Необходимо установить:
  * **Google Chrome**
  * **Mozilla Firefox**

## 2. Изучение тестовых сценариев
Необходимо покрыть автотестами следующие сценарии:

### Сценарий 1. Выпадающий список в разделе «Вопросы о важном»
  Проверить, что при нажатии на стрелочку открывается соответствующий текст.
### Сценарий 2. Заказ самоката
  Проверить позитивный сценарий оформления заказа с двумя наборами данных.

**Особенности:**
* Есть две точки входа в сценарий:
    * кнопка «Заказать» вверху страницы.
    * кнопка «Заказать» внизу страницы.
* В приложении присутствует баг, который не позволяет оформить заказ в браузере Google Chrome.

**Шаги позитивного сценария:**
1. Нажать кнопку «Заказать».
2. Заполнить форму заказа.
3. Убедиться, что появилось всплывающее окно с сообщением об успешном создании заказа.

## 3. Написание тестов

### 3.1. Определение локаторов
  1. Создать класс для описания элементов главной страницы в отдельном пакете.
  2. Составить список элементов с комментариями — указать понятные названия, чтобы ничего не упустить при поиске локаторов.
  3. Под каждым элементом указать локатор.
### 3.2. Описание локаторов с помощью Page Object
  1. Создать отдельный пакет для Page Object.
  2. Для каждой страницы сервиса создать отдельный класс с описанием её элементов через Page Object.
### 3.3. Написание тестов на Selenium
  1. Организовать структуру файлов проекта:
      * все тесты должны находиться в директории `test`;
      * сгруппировать тесты по функциональности.
  2. Убедиться, что браузер закрывается в каждом тесте — использовать метод `driver.quit()` в конце теста.
  3. Проверить, что тесты запускаются и проходят хотя бы в одном браузере.

## Важные замечания
* Не создавать отдельный класс для каждого теста — объединить тесты одной функциональности в один класс.
* Обязательно использовать параметризацию там, где это уместно.
* Отчёт о тестировании не требуется.

## Запуск в нужном браузере
  * Для Chrome (по умолчанию):
     `mvn test`
  * Для Firefox:
     `mvn test -Dbrowser=firefox`
